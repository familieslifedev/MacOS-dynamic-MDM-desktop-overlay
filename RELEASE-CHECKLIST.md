# Release readiness checklist

- [ ] Confirm redistribution rights for upstream source and derived binaries (see NOTICE.md)
- [ ] Review copyright attribution and obtain contributor agreement for MIT licensing of original contributions
- [ ] Confirm `.gitignore` prevents local coordinates and third-party wallpaper assets from being committed
- [ ] Compile and run the manager and overlay on supported macOS versions
- [ ] Verify manager section navigation, collection selection and gallery hit testing
- [ ] Verify first-run setup, static and solar modes, multiple displays, sleep/wake and recovery
- [ ] Test a clean source checkout and document known installation limitations
- [ ] Review app signing and notarisation before distributing binaries
- [ ] Confirm version numbers, release notes and archive contents
