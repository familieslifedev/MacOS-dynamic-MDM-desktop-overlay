# Contributing

Contributions and issue reports are welcome. Please describe the macOS version, steps to reproduce and expected/actual behaviour. Do not include local configuration, precise coordinates, copyrighted wallpaper files, personal data or confidential device-management details in issues or pull requests.

Build the manager with `bash build-manager.sh`. Keep source changes focused, describe user-facing changes in the appropriate version changelog, and verify menu bar interactions, overlay start/stop and wallpaper selection on macOS before submitting.

**Licensing:** contributors should submit only code they are entitled to license. The upstream code's redistribution permissions remain unresolved; see [NOTICE.md](NOTICE.md).
