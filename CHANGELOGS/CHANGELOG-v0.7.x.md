# v0.7.x — Wallpaper gallery and interface updates

## Changes

- Introduced a larger wallpaper gallery with frame-by-frame browsing.
- Added support for browsing eight-frame collections and sixteen-frame Solar Gradients collections.
- Added a placeholder for missing preview frames.
- Improved overlay status visibility and installation validation refresh.
- Browsing previews does not modify the active wallpaper.

### v0.7.1

- Constrained the menu bar interface to a scrollable, height-limited panel to accommodate the expanded gallery.

### v0.7.2

- Replaced section selection with dedicated navigation buttons.
- Replaced the wallpaper collection picker with a menu-based selector.
- Retained existing gallery navigation.

### v0.7.3

- Disabled mouse hit-testing on the non-interactive wallpaper preview to prevent it from intercepting clicks on other controls.
- Restored interaction with section navigation and wallpaper collection selection.

### v0.7.4

- Consolidated the v0.7 gallery and navigation fixes into the stable v0.7 release line.
